# 기능 현황

야간 안심 귀가 앱의 현재 구현 상태와 최근 변경 사항을 추적하는 문서다.

## 상태 표기

| 상태 | 의미 |
| --- | --- |
| `완료` | 사용자 흐름과 기본 API 연동까지 연결되어 현재 데모 가능한 상태 |
| `진행 중` | 화면 또는 API 일부는 연결됐지만 검증, 예외 처리, 후속 연동이 남은 상태 |
| `보류` | 요구 범위는 정리됐지만 아직 구현하지 않았거나 다음 단계로 미룬 상태 |

최종 점검: 2026-09-11. 기능표는 로컬 작업 트리 기준이며, 이번에 확인한 경로 선택 변경과 관리자 회원·시설물 관리 구현은 아직 미커밋 상태다. 서버 및 실기기 동작은 별도 검증이 필요하다.

## 다음 세미나까지 할 일

- 도로 오버레이와 위험 구역 판단 기준을 `final_score`와 5단계 안전 등급으로 통일하고, 현재 `safety_score` 기반 로직과 차이를 설명할 수 있게 정리한다.
- 빠른길과 안전한길 모드가 실제 `/route` 응답에서 어떻게 달라지는지 샘플 경로로 검증하고 발표용 비교 근거를 남긴다.
- 주변 시설물 표시 범위를 어디까지 데모 범위로 볼지 정리하고, 시설물 정보가 안전도 설명과 어떻게 이어지는지 문구를 다듬는다.
- 관리자 신고 처리와 백그라운드 위험 구역 알림을 실제 기기 기준으로 검증해 실패 케이스와 권한 요구사항을 정리한다.
- 비상 연락처 기능을 다음 단계 SOS 흐름과 어떻게 연결할지 범위를 정리한다.

새로 확인된 사용자 전달 세미나 할 일은 없어서, 기존 항목은 중복 없이 현재 구현 상태에 맞게만 정리했다.

## 현재 중점 작업

- 백그라운드 위험 구역 감시와 즉시 알림 흐름을 실제 Android 환경에서 안정화한다.
- 명시적인 경로 모드 선택, 즐겨찾기 재사용, SOS 요청이 메인 화면 동선에서 자연스럽게 이어지도록 연결 범위를 다듬는다.
- 경로 안전도 계산 기준을 문서와 UI 설명까지 포함해 일관되게 맞춘다.
