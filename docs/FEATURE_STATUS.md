# 기능 현황

야간 안심 귀가 앱의 현재 구현 상태와 최근 변경 사항을 추적하는 문서다.

## 상태 표기

| 상태 | 의미 |
| --- | --- |
| `완료` | 사용자 흐름과 기본 API 연동까지 연결되어 현재 데모 가능한 상태 |
| `진행 중` | 화면 또는 API 일부는 연결됐지만 검증, 예외 처리, 후속 연동이 남은 상태 |
| `보류` | 요구 범위는 정리됐지만 아직 구현하지 않았거나 다음 단계로 미룬 상태 |

## 기능표

### 1. 회원 관리

| 기능 | 상태 | 현재 구현 상태 |
| --- | --- | --- |
| 회원가입 | `완료` | 아이디, 비밀번호, 이름, 전화번호, 성별, 생년월일 입력 기반 회원가입 흐름이 연결돼 있다. |
| 로그인 | `완료` | 아이디와 비밀번호 기반 로그인, 사용자 ID 전달, 관리자 분기까지 연결돼 있다. |
| 비밀번호 찾기 | `진행 중` | 비밀번호 재설정 화면과 `/password-reset` 호출은 연결됐지만 서버 계약 검증과 본인 확인 규칙 정리가 남아 있다. |
| 내 정보 수정 | `진행 중` | 프로필 조회, 이름/전화번호/생년월일/성별 수정, 비밀번호 변경 호출까지 연결됐지만 세션 처리와 실패 케이스 검증이 더 필요하다. |

### 2. 지도 및 경로

| 기능 | 상태 | 현재 구현 상태 |
| --- | --- | --- |
| 현재 위치 기반 지도 보기 | `완료` | 현재 위치 이동, 검색 결과 카메라 이동, 출발지/도착지 선택, 경로 폴리라인 렌더링이 연결돼 있다. |
| 장소 검색 | `완료` | `/search/places` 기반 검색, 결과 목록, 선택 시 지도 반영 흐름이 메인 화면과 지도 화면에 연결돼 있다. |
| 즐겨찾기 장소 저장/재사용 | `완료` | 선택한 위치를 즐겨찾기에 저장/삭제하고, 저장한 장소를 다시 선택해 현재 위치 기준 목적지로 바로 경로 탐색하는 흐름이 연결돼 있다. |
| 빠른길/안전한길 경로 탐색 | `진행 중` | 가이드 시트에서 `/route` 호출과 경로 렌더링까지 연결됐지만 두 모드 차이 검증과 안전 점수 반영 결과 확인이 남아 있다. |
| 도로 안전도 오버레이 | `진행 중` | 지도 bounds 기준 `/roads` 조회와 오버레이 렌더링은 연결됐지만 `final_score` 기준 통일과 5단계 안전 등급 정리가 남아 있다. |
| 경로 옵션 비교 | `보류` | 추천 경로와 대안 경로를 비교해 선택하는 UI와 설명은 아직 없다. |

## 다음 세미나까지 할 일

- 도로 오버레이와 위험 구역 판단 기준을 `final_score`와 5단계 안전 등급으로 통일하고, 현재 `safety_score` 기반 로직과 차이를 설명할 수 있게 정리한다.
- 빠른길과 안전한길 모드가 실제 `/route` 응답에서 어떻게 달라지는지 샘플 경로로 검증하고 발표용 비교 근거를 남긴다.
- 주변 시설물 표시 범위를 어디까지 데모 범위로 볼지 정리하고, 시설물 정보가 안전도 설명과 어떻게 이어지는지 문구를 다듬는다.
- 관리자 신고 처리와 백그라운드 위험 구역 알림을 실제 기기 기준으로 검증해 실패 케이스와 권한 요구사항을 정리한다.
- 비상 연락처 기능을 다음 단계 SOS 흐름과 어떻게 연결할지 범위를 정리한다.

새로 확인된 사용자 전달 세미나 할 일은 없어서, 기존 항목은 중복 없이 현재 구현 상태에 맞게만 정리했다.

## 현재 중점 작업

- 백그라운드 위험 구역 감시와 즉시 알림 흐름을 실제 Android 환경에서 안정화한다.
- 알림 설정의 기본 경로 저장, 즐겨찾기 재사용, SOS 요청이 메인 화면 동선에서 자연스럽게 이어지도록 연결 범위를 다듬는다.
- 경로 안전도 계산 기준을 문서와 UI 설명까지 포함해 일관되게 맞춘다.
